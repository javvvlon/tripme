# Документы

`TripMe-Лиды-и-Заказы.pdf` — руководство для менеджеров: как лид становится заказом,
что означает каждый статус и какие правила система не даст нарушить.

Собирается из `leads-orders.source.html`. В исходнике вместо шрифта и логотипов стоят
метки `__FONT_B64__`, `__LOGO_LIGHT_B64__`, `__MARK_B64__` — они подставляются из
`public/fonts` и `public/brand` перед печатью, чтобы PDF ни от чего не зависел.

Пересобрать:

```bash
node docs/build-pdf.mjs
```
